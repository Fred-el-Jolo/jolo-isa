## Problem

## Out of Scope

No code, installer, skill, test or global-rule file is changed in this task: the spec is for discussion. The spec does not settle questions that belong to the user; it lists them with a recommendation.

## Constraints

- Spec style follows the existing `future/*.md` specs: numbered sections, plain sentences, decisions and open questions kept apart.
- Every runtime file the spec names must exist (or be marked new).
- Global rules must cover both harnesses: Claude Code (`~/.claude/CLAUDE.md`) and pi (`~/.pi/agent/AGENTS.md`).
